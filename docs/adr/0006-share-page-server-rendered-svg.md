# 分享页在服务端把图表渲染成 SVG，访问权限实时校验

Share Link 页面由 RSC 读取 Snapshot，在服务端用 ECharts 的 SSR 能力把图表渲染成 SVG 直接输出，首屏不加载任何图表 JS；用户开始交互或浏览器空闲时，再加载完整的 ECharts 接管图表。页面内容按 boardId 打缓存标签，Board 被编辑时让标签失效。**但链接是否已撤销、是否已过期，每次请求都必须实时校验，不能走缓存**，否则撤销后的链接仍然能被访问。之所以不直接在客户端渲染，是因为分享页是外部访客（常常在手机上）接触产品的第一个页面，首屏 JS 和 LCP 的预算都是按这个页面定的。
