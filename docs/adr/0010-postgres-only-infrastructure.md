# 基础设施只有 Postgres、对象存储和应用本身：不用 Redis，不用消息队列

AI Quota 在 Postgres 里按（用户、北京时间日期）各存一行，扣减用一条带条件的原子 UPDATE 完成，天然防止并发超扣，也不需要定时重置；鉴权接口的限流直接用 Better Auth 内置功能，计数存在数据库里；"一键体验"按 IP 限流，防止靠不断新建 Guest 来绕过 Quota。定时任务（清理过期 Guest、清理没有确认上传的文件、清理已删除 Dataset 的文件）由一个带密钥保护、可以重复执行的 `/api/cron/[job]` 路由承载，由外部调度器定时触发。这样做让系统只依赖三个组件，部署到 Vercel 或香港服务器都不需要改代码。如果以后并发量增长到 Postgres 的计数写入成为瓶颈，再引入 Redis。
