# 会话列表自己用 TanStack Virtual 实现虚拟化和"粘底"，图表使用固定高度

Conversation 的消息列表用 @tanstack/react-virtual 做虚拟化，自动滚动到底部（粘底）和滚动锚定都自己实现，没有采用自带跟随底部功能的 react-virtuoso：它专门为聊天场景设计的组件需要商业授权，而且这部分是我们刻意要亲手掌握的前端能力。判断用户是否主动离开底部，依据的是滚轮、触摸、键盘等用户意图事件，而不是单纯的 scroll 事件，因为程序自己触发的滚动也会产生 scroll 事件。

## Consequences

- Answer 里的图表**必须使用按图表类型固定的高度**（骨架屏同样尺寸），让条目高度在图表初始化之前就确定下来。改成"图表高度随内容自适应"会破坏虚拟列表的测量和滚动锚定。
- 快照数据在条目进入视口时才拉取，因此只有可见的图表才会产生网络请求和 ECharts 实例。
